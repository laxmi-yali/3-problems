# 3-problems

This repository contains three beginner-friendly real-world Python projects. These projects help improve Python programming skills through practical applications.

🚀 Projects Included

1. Online Shopping Cart System

Description:
A Python application that allows customers to select products, enter quantities, and calculate the total shopping bill.

Features:

Display available products and prices.

Select products.

Enter product quantities.

Calculate the total bill.

Handle unavailable products.

Concepts Used:

Dictionary

For loop

While loop

If-else statements

Arithmetic operators
